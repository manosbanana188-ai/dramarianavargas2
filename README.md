# Site – Dra. Mariana Vargas de Melo

Site institucional da Dra. Mariana Vargas de Melo, cirurgiã-dentista em Vitória/ES.

- Página única: `index.html` (CSS, fontes, foto e animações GSAP já embutidos)
- Ícones: `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png`, `icon-512.png`, `site.webmanifest`
- Prévia de compartilhamento: `og-image.jpg` (1200×630)

## Publicação
Hospedado na Vercel (projeto `dramarianavargas`). Cada commit na branch principal publica automaticamente.

## Onde editar
- WhatsApp e Google Analytics: bloco `CONFIG` no fim do `index.html`
- Endereço/URL do site: tags `canonical`, `og:url`, `og:image` e o JSON-LD no `<head>`
- Comentários `EDITAR` marcam os trechos de conteúdo
